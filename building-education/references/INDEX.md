## Themes
- Walled courtyard = privacy/security for urban Accra plots
- Through-lot planning (front + rear road access)
- Engineered R.C. perimeter walls (column + tie-beam frame, stone-clad)
- Split-level / 2-story with roof decks
- Pool + jacuzzi + underground pump/filtration
- Flat-roof waterproofing = #1 Accra failure risk
- Security without razor wire (barb-less edge, CCTV, electric gate)
- Vertical zoning: stack by USE (ground=public/service, first=sleeping, roof=entertainment)
- Reading real working drawings: marcus consult conventions (black walls, blue openings, red stairs, cyan plumbing, scale 1:100)
- Local Accra typology: house-boy/staff room, 2-car garage + porch, detached gym/pool pavilion
- Material restraint: a 5-material palette (white + wood slats + stone + black glass + grey) repeated with discipline reads as luxury
- Layered warm lighting (soffit LED + sconce + landscape + pool) is what makes twilight/night shots look expensive
- Carport (open, showcase) vs enclosed garage — Accra heat/dust trade-off
- Gate hierarchy: slat gate + pillars + porte-cochère + glass foyer + stone wall + leaf-screen + guardhouse = full entrance composition
