# SKILL: Akoma Brand Content Strategist

## DESCRIPTION
Executed every Thursday at 9:00 AM. This skill generates a high-engagement 7-day social media content plan for the Akoma brand. It synthesizes recent business activity into platform-specific posts to maintain brand consistency and momentum.

## CAPABILITIES
- Content Strategy & Ideation
- Multi-Platform Optimization (IG/TikTok/X)
- Automated Editorial Calendar Generation

## WORKFLOW

### 1. Context Gathering
Read the following files to find "hook" ideas:
- `memory/projects.md` (Look for Akoma Robotics or related milestones).
- `memory/$(date +%Y-%m-%d).md` (Check for recent "Key Wins").
- `memory/briefings/` (Scan the last 3 days for interesting data points).

### 2. Content Generation
Create a 7-day schedule. For each day, provide:
- **Platform**: Instagram, TikTok, or Twitter (X).
- **Type**: Photo, Video, Reel, or Thread.
- **Hook/Caption**: A compelling opening and body text.
- **Hashtags**: 5-10 relevant tags (e.g., #AkomaRobotics #TechGhana #Innovation).
- **Best Time**: Recommended posting time based on regional audience activity.

### 3. Documentation
Save the full plan to `memory/content/AKOMA_CONTENT_PLAN_$(date +%Y-%m-%d).md` using this table format:

| Day | Platform | Content Type | Caption Idea | Hashtags | Posting Time |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Mon | ... | ... | ... | ... | ... |
| Tue | ... | ... | ... | ... | ... |
| ... | ... | ... | ... | ... | ... |

### 4. Notification
Post a summary of the plan to **Telegram Topic 29 (#content)**.
The summary should include:
- The "Theme of the Week."
- A list of the Top 3 "Must-Post" items from the plan.
- A confirmation that the full file is saved in the `memory/content/` folder.

## GUIDELINES
- **Brand Voice**: Innovative, community-focused, and tech-forward.
- **Visual Cues**: Suggest specific visual elements (e.g., "Show the internal wiring," "Time-lapse of the assembly").
- **Persona**: The Librarian (Creative Strategist mode) - organized and visionary.
- **Error Handling**: If no recent project updates are found, generate a "Brand Awareness" plan focusing on the core mission of Akoma.
