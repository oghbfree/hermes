# SKILL: 2Real Shop & Warehouse Content Planner

## DESCRIPTION
Executed every Friday at 9:00 AM. This skill generates a high-impact 7-day content plan for 2Real Shop. It focuses on retail inventory, warehouse "behind-the-scenes" logistics, and customer engagement to drive shop traffic and transparency.

## CAPABILITIES
- Retail Marketing Strategy
- Logistics & Warehouse Storytelling
- Multi-Platform Scheduling (IG/TikTok/X)

## WORKFLOW

### 1. Shop Contextualization
Read the following to identify "Real-World" content hooks:
- `memory/projects.md` (Look for "2Real Shop" or "Warehouse" milestones).
- `tasks-queue.md` (Check for upcoming deliveries or stock takes).
- `memory/briefings/` (Scan the last 2 days for "Business Pulse" updates on 2Real).

### 2. Strategic Ideation
Create a 7-day schedule focusing on the mix of "Shop/Product" and "Warehouse/Process."
For each day, provide:
- **Platform**: Instagram, TikTok, or Twitter (X).
- **Type**: Photo, Video, Reel, or Post.
- **Caption Idea**: Engaging copy focusing on authenticity and "Realness."
- **Hashtags**: Specific tags like #2RealShop #WarehouseLife #AccraRetail #Logistics.
- **Best Time**: Recommended posting time for retail peak engagement.

### 3. Documentation
Save the full plan to `memory/content/2REAL_CONTENT_PLAN_$(date +%Y-%m-%d).md` using this table format:

| Day | Platform | Content Type | Caption Idea | Hashtags | Posting Time |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Sat | ... | ... | ... | ... | ... |
| Sun | ... | ... | ... | ... | ... |
| ... | ... | ... | ... | ... | ... |

### 4. Notification
Post a summary of the plan to **Telegram Topic 29 (#content)**.
The summary must include:
- The "Main Promotion" of the week.
- One "Warehouse Insight" content idea.
- Confirmation of the file path in `memory/content/`.

## GUIDELINES
- **Brand Voice**: Authentic, "boots-on-the-ground," transparent, and reliable.
- **Visual Style**: Industrial but clean (Warehouse shots), vibrant and welcoming (Shop shots).
- **Persona**: The Librarian (Retail Strategist mode).
- **Error Handling**: If no specific inventory updates are found, focus the plan on "Warehouse Efficiency" and "Customer Service" pillars.
