# SOP: Jiji & Facebook Listing Workflow — 2 Real Enterprises

**Version:** 1.0 | **Date:** 2026-05-16 | **Approved by:** H

## Overview
John creates and manages all listings on Jiji Ghana and Facebook Marketplace. This SOP covers the end-to-end workflow from stock identification to published listing.

## When to List

| Trigger | Action |
|---------|--------|
| New stock arrives | List within 48 hours |
| Item has been in stock 30+ days with no enquiries | Refresh listing (new photos, adjust price) |
| Stock running low (1-2 units) | Mark as "Limited" in title |
| Item out of stock | Remove/disable listing immediately |
| H requests specific item to be listed | Priority — list same day |

## Jiji Listing Workflow

### Step 1: Prepare
1. Confirm item is in Zobase with correct price
2. Take 3-5 photos: front, back, side, serial number/label, any defects
3. Use good lighting (natural light preferred, no flash glare)
4. Clean item before photographing

### Step 2: Create Listing
1. Log in to Jiji Ghana (John's account)
2. Select correct category and subcategory
3. **Title:** Brand + Model + Key Feature + Condition (e.g., "DeWalt DCD796 Cordless Drill 20V - New")
4. **Description:**
   - Specifications (voltage, size, capacity, etc.)
   - Condition (New / Used - Like New / Used - Good)
   - What's included (item only, with charger, with case, etc.)
   - Warranty info if applicable
   - "Price is firm" or "Negotiable" (per H's instruction)
5. **Price:** From Zobase POS — exact match
6. **Location:** Accurate location (Oyarifa / Kantamanto)
7. **Photos:** Upload all, best photo first
8. **Contact:** John's WhatsApp number

### Step 3: Review & Publish
9. Proofread title, description, price
10. Verify photos are clear and correctly oriented
11. Publish
12. Copy listing URL and save to `listings-tracker.md`

### Step 4: Maintain
13. Respond to enquiries within 2 hours during business hours
14. Mark as "Sold" immediately after sale
15. If no enquiries in 14 days: refresh (repost with new photos)

## Facebook Marketplace Listing Workflow

### Step 1: Prepare
Same photo requirements as Jiji

### Step 2: Create Listing
1. Open Facebook → Marketplace → Create New Listing
2. Select "Item for Sale"
3. Upload photos (best first)
4. **Title:** Same format as Jiji
5. **Price:** From Zobase POS — exact match
6. **Category:** Select most accurate
7. **Condition:** New / Used - Like New / Used - Good
8. **Description:** Same as Jiji description
9. **Location:** Set to shop location
10. **Delivery:** "Local pickup" (unless H approves delivery)

### Step 3: Publish & Share
11. Publish listing
12. Share to relevant Facebook groups (with group rules compliance)
13. Share to 2 Real Facebook page

## Listing Quality Standards

- **Photos:** Minimum 3, well-lit, clean background, serial numbers visible
- **Titles:** No ALL CAPS, no excessive emojis, clear and descriptive
- **Descriptions:** Complete specs, honest condition, no misleading claims
- **Pricing:** Must match Zobase POS exactly
- **Response time:** Within 2 hours during business hours (8 AM - 8 PM)

## Platform Rules

### Jiji Ghana
- One listing per item (no duplicates)
- No contact info in description (Jiji provides messaging)
- Respond to Jiji messages promptly — response rate affects visibility
- **Note:** Jiji Ghana is behind Cloudflare — browser access only for management

### Facebook Marketplace
- No prohibited items (check FB commerce policies)
- Accurate category selection
- Price must be realistic (FB may flag unrealistic prices)
- Share to max 5 relevant groups per listing

## Listing Tracker

John maintains `listings-tracker.md` with:
- Date listed
- Platform (Jiji / FB)
- Item name
- Price
- URL
- Status (Active / Sold / Expired / Removed)
- Enquiry count

## Pitfalls
- **Never list items with <2 units** without H's approval (risk of overselling)
- **Don't use stock photos** — always use actual product photos
- **Don't inflate prices** on Jiji expecting negotiation — price must match Zobase
- **Remove sold items immediately** — don't let customers enquire on sold stock
- **Don't share personal number in Jiji descriptions** — use Jiji messaging
- **Cloudflare blocks automated scraping** of Jiji — browser management only
