**Version:** 1.0 | **Date:** 2026-05-16 | **Approved by:** H

## Overview
Track and maintain all Akoma Robotics equipment — primarily mBot kits, laptops, and accessories.

## Condition Ratings

| Rating | Meaning | Action |
|--------|---------|--------|
| New | Unboxed, unused | Ready for deployment |
| Good | Working, minor wear | Ready for deployment |
| Fair | Working, needs minor repair | Repair before next use |
| Poor | Not working | Repair or retire |
| Retired | Beyond repair | Dispose, update register |

## Maintenance Schedule

### Before Each Class
- Charge all mBot batteries
- Test all sensors (IR, ultrasonic, Bluetooth)
- Verify mBlock software on laptop
- Count all pieces (no missing parts)

### Monthly
- Full inventory count — match physical to register
- Update condition ratings
- Replace worn cables, lost screws, dead batteries
- Clean mBot chassis and wheels
- Check laptop for software updates

### Quarterly
- Deep clean all kits
- Test battery health (replace if <50% capacity)
- Review register — retire unusable equipment
- Report to H: equipment status, replacement needs

## Loss & Damage Protocol
1. Log incident: what, when, who, cause
2. If student damage: assess if repairable
3. If repairable: fix and note in register
4. If not repairable: note as "Poor" — H decides replacement
5. If lost/stolen: report to H immediately
6. **Never hide losses** — H needs accurate equipment data

## Procurement
- New kits: H approves all purchases
- John can request: submit item, quantity, supplier quote to H
- Minimum stock: enough for largest class + 20% buffer
- Track lead times — order 4 weeks before new course starts

## Storage
- Store in dry, cool location (not in direct sunlight)
- Keep in original boxes or organized bins
- Label all bins by content
- Keep away from metal tools (magnets affect sensors)
