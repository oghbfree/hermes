# Weekly Health Analysis Template

## Purpose
Structure and guidance for the weekly health analysis generated by the health-analysis-weekly cron (Sunday 09:06).

## File Naming
- H: `memories/health/weekly/H-YYYY-MM-DD.md` (date = Sunday/end of reporting week)
- Comfort: `memories/health/weekly/MUM-YYYY-MM-DD.md`
- Dad: `memories/health/weekly/DAD-YYYY-MM-DD.md`

## Data Sources (in priority order)
1. **Structured health logs** (primary):
   - H: `memories/health/H/HEALTH_LOG_YYYY-MM.md`
   - Comfort: `C:\Users\User\CARE_LOG_COMFORT_YYYY-MM.md`
   - Dad: `C:\Users\User\CARE_LOG_DAD_YYYY-MM.md`
2. **Integrated daily synthesis files** (secondary/free-text):
   - `memories/insights/INTEGRATED_INSIGHTS_YYYY-MM-DD.md` — scan past 7 days for free-text health mentions
3. **Weekly report files** (trend comparison):
   - Previous 3–4 weekly reports for the same person

## Required Sections

### 1. Data Completeness Table
Per person, per day: Morning | Afternoon | Evening | Structured fields. Overall response rate.

### 2. Last Known Data Point
Date and summary of the most recent actual health entry.

### 3. Meal/Nutrition Pattern (if data exists)
Table of meals across available days. Note nutritional quality, consistency, concerns.

### 4. Symptom Tracking
Table: Date | Symptoms | Severity | Action taken. Link to known conditions.

### 5. Known Conditions & Current Status
Per condition: last data point, complications to watch, status indicator.

### 6. Red Flags
Grouped by severity: Critical (immediate), Moderate (this week), Stable/Positive.

### 7. Weekly Trend Comparison
Table comparing current week vs. 3–4 prior weeks for key metrics.

### 8. Root Cause Analysis (if data gaps exceed 3 days)
Distinguish: delivery failure, response failure, capture failure, channel failure.

### 9. Recommendations
Numbered, ranked by severity, with timeframe.
