# Structured Care Document Template

## Purpose
Template for creating a structured care document for an elder care patient. This is the master reference document that gets updated with every new piece of medical correspondence.

## File Naming
`<DOCUMENT_TYPE>_<PATIENT_INITIALS>.md` — e.g., `FAMILY_INSIGHTS_DAD.md`

## Section Structure

### Header
```markdown
# Family Insights — [Patient Name]
## Structured Care Document: [Full Name]

> **Last updated:** YYYY-MM-DD
> **Next review:** Upon new hospital correspondence or monthly
```

### 1. Patient Snapshot
Table with: Full Name, DOB, age, NHS Number, Hospital MRN, Address, Phone, Email, GP (name + address + phone), Next of Kin (name + phone), Ethnicity, Language, Resuscitation Status, Allergies.

### 2. Medical Timeline
Chronological table: Date | Event | Location | Clinician. Group by year. Include admissions, procedures, key outpatient visits.

### 3. Active Conditions
Table: Condition | Status (Active/Historical) | Onset | Notes. Rank by clinical significance.

### 4. Current Medications
Table: Medication | Dose | Frequency | Route | Indication | Notes. Flag controlled drugs, DAPT, and interaction warnings.

### 5. Care Package
- Provider details (council, agency)
- Schedule (visit times, hours/week)
- Equipment (wheelchair, keysafe, alarms, etc.)
- Active referrals table
- Costs and invoicing

### 6. Mobility & Function
Table covering: Transfers, Wheelchair use, Outdoors, Prosthesis, Falls risk, Smoking, Alcohol.

### 7. Upcoming Appointments
Table: Date | Time | Clinic | Location | Purpose.

### 8. Hospital Correspondence Log
Table: Date Received | Document Type | Source | Key Points. One entry per document.

### 9. Red Flags & Escalation
- Immediate escalation criteria (vitals thresholds, specific symptoms)
- Escalation path (who to contact in order)

### 10. Financial Tracking
Table: Period | Amount | Status | Notes. Include annual cost estimate.

### 11. Key Contacts
Table: Role | Name | Organisation | Contact.

## Update Protocol
1. Log in Section 8 (Correspondence Log)
2. Update Section 2 (Timeline) if new procedures/events
3. Update Section 4 (Medications) if meds changed
4. Update Section 7 (Appointments) if new dates
5. Update Section 3 (Conditions) if new diagnoses
6. Update header date
