## Quick Reference

Key Metrics:
- Phase 1 Investment: 3,000-5,000 USD
- Per-client hardware cost: ~200 USD
- Monthly subscription: GH500-1,000
- Break-even: 2.5-5 months per client

Priority Applications:
1. Fall Prevention (highest)
2. Vital Monitoring (high)
3. Companionship (medium)

Key Suppliers:
- Essence SmartCare (enterprise)
- Made-in-China (wholesale)
- Transtek (BP monitors)
- Alibaba (motion sensors)
