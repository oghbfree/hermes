RECOMMENDED TECH STACK

HARDWARE (Low-cost, importable)
- Wearable fall detection sensors: -80/unit
- Bluetooth BP monitors: -60/unit
- Motion/activity sensors: -40/unit
- Solar chargers/batteries: Essential for power backup

SOFTWARE
- WhatsApp Business API: Primary communication channel
- Cloud dashboard: Simple web interface for caregivers
- SMS gateway: Fallback for poor connectivity
- Mobile Money API: MTN/Vodafone integration

AI COMPONENTS
- Speech recognition: Google Cloud (Twi dialects support)
- Health prediction: Pre-trained models (no need to build from scratch)
- Chatbot: Dialogflow or Rasa with local language support
- Triage system: Rule-based + ML for symptom assessment

CONNECTIVITY STACK
- Primary: 4G/3G cellular data
- Fallback: SMS (Twilio or local provider)
- WhatsApp: Primary channel
- Cloud: AWS or Google Cloud (affordable tiers)

SECURITY & PRIVACY
- HIPAA-compliant data handling
- End-to-end encryption for patient data
- Local data storage options for compliance
- Regular security audits

INTEGRATION POINTS
- Mobile Money: MTN Momo API
- WhatsApp: Official Business API
- SMS: Local telecom partnerships
- Cloud: Standard APIs
