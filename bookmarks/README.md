# Bookmarks

This folder contains the exported bookmarks from [booky.io](https://booky.io/), converted to Obsidian-friendly markdown.

## Files

| File | Description |
|------|-------------|
| [[booky-export]] | Full bookmark export, organized by folder/category |

## Notes

- Bookmarks are organized by their original booky.io folder structure
- Empty folders are noted but don't contain any links
- Original HTML descriptions/annotations have been preserved beneath each link
