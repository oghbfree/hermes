# SOP — Weekly Flash Sale Asset Production
> Trigger: recurring sale cycle (weekly).

1. Pick 3–5 SKUs from Zobaze (real SKUs/prices; stock confirmed physically).
2. Build asset set per channel: WhatsApp broadcast (bullets + image), Jiji spotlight, status/story images.
3. Assets from `content-assets/[brand]/`; brand rules [[SOP-BRAND-IDENTITY]] (locked faces, no invented logos/text).
4. One price-discount structure, approved by H (same authority rule as [[SOP-2REAL-ESCALATION]]).
5. Publish on schedule (same day/time each week — consistency beats volume).
6. Log sale results vs baseline in the tracker Summary tab; feed winners to next week.
