# SOP — Daily Sales Close (Tue–Sat)
> Trigger: end of trading day (before staff leave / before 18:00).

1. Count physical cash + MoMo receipts → compare to Zobaze POS day summary. **Zero variance is the target.**
2. Log the day to `business/2real/daily-sales-log.md` (H's daily log): revenue, top SKUs, MoMo vs cash split, anomalies.
3. Stock room: items sold today marked; anything below reorder point → sourcing list ([[SOP-2REAL-ENQUIRY-HANDLING]]).
4. Dispatches: all riders confirmed delivered or flagged → escalation templates.
5. Any discrepancy: photo evidence + note in tracker Write-Off/Summary tab + H WhatsApp same day.
6. Jiji stats entry (see [[SOP-2REAL-JIJI-DOMINANCE]]) if not yet done at 16:00.

**Rule:** if it's not in the tracker + daily-sales-log, it didn't happen.
