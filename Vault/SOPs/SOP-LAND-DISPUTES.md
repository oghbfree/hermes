# SOP — Stool Land Disputes (Ghana)

## Workflow
1. **Evidence pack first:** indenture/site plan, receipts, witness names, photos with GPS/date, prior letters — into the case folder under `Vault/` (one folder per dispute).
2. **Timeline build:** chronology table — date, event, evidence ref, parties. Facts only; assertions marked as claims.
3. **Letter drafting:** formal register (NOT the brand voice), addressed to the customary authority (stool/chief) first; copy parties. One issue per letter, one ask per letter.
4. **H reviews and sends everything.** Agents never sign, never commit, never pay — customary processes are H-decisions with family input.
5. **Log every contact** (date, who, what said) back into the case folder timeline.

## Rules
- Never threaten, never cite wrong statute, never suggest payments to agents/intermediaries in writing.
- Family context matters (Felicia, elders) — personal channels stay open to H; letters stay formal.
- Where a dispute touches the portfolio, cross-link the property in `insights/real-estate-portfolio.md`.
