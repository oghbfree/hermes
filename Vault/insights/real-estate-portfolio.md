## Ghana Building Cost Reference — Price Guard

*Use these benchmarks to verify quotes and avoid overcharging (recorded 14/8/26)*

### Cement & Block Rates

| Rate | Value |
|------|-------|
| **1 bag cement (50kg)** | ~100 GHS |
| **6" blocks per bag** | 35 pieces |
| **5" blocks per bag** | 40 pieces |
| **Labour per bag** | 30 GHS/bag |
| **Avg person per day** | 5 bags |
| **Strong person per day** | 7-8 bags |

### Block Estimates Per Build Scope

| Build Type | 5" Solid Blocks Required | Roofing Sheets |
|-----------|------------------------|----------------|
| 1 room (12×12 ft) | 800 | 8 |
| 2 bedrooms | 1,600 | — |
| 2 bed chamber & hall | 4,000 | — |

### Average Room Dimensions (Standard)

| Room | Size |
|------|------|
| Hall | 10ft × 10ft |
| Kitchen | 10ft × 6ft |
| Bedroom | 12ft × 12ft |
| Washroom | 5ft × 9ft |

### How to use this

When a contractor quotes you:
1. **Blocks**: Total blocks ÷ rate per bag = bags of cement needed. Multiply by 100 GHS.
2. **Labour**: Bags × 30 GHS = daily labour cost. Check if they're quoting per bag or per day.
3. **Build scope**: Cross-check their block count against the reference table above.
4. **Cement price**: Current market is ~100 GHS/bag — if they quote higher, ask why.
