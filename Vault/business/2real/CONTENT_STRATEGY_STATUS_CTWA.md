| Audience | Accra, 25–45, gaming/toys/family interests | Accra, 22–55, DIY/construction/solar interests |

### Rules
- Run 5–7 days before judging. Kill metric = **chats per cedi**, not clicks.
- If one ad set ≥1 chat/day → shift budget to winner. Both dead after 7 days → change creative, not budget. Scale budget only when chat→sale is proven.
- Weekly creatives = that week's Status Deal of the Day + one pillar hero item (same photo shoot).

## 4. Measurement (what counts)

- **Status:** replies per post (chats that reference "the status") — log in daily-sales-log NOTES
- **CTWA:** chats/day per ad set, chats→sale rate; kill metric = chats per cedi
- **Signal over noise:** chats and sales only. Impressions/reactions = noise (per 2Real metrics discipline)
