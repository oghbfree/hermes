Append one line per day. The 4:30 AM briefing reads this file.

|------|--------------|--------------|------------|-------|

| 17/08/26 |  | — |  | Day off (with mum) |
| 19/08/26 |  | — |  | Day off (property viewing) |
|  |  |  |  |  |

## How to Use
Each evening (or next morning before 4:30 AM), add one line:
```
13/07/26 | 800 | 920 | JBL Speaker, Samsung Charger, Powerbank | Good day, rain held off
```

The briefing will auto-calculate:
- Variance (actual - target)
- % variance
- Pace note for tomorrow
