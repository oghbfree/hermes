## 📋 CAPTION FORMULAS (Per Platform)

### FACEBOOK / INSTAGRAM (Detail + Context)

**Length:** 60-120 words (FB), 50-100 words (IG)  
**Structure:** Hook (1 line) → Examples (2-3 concrete beats from VO) → Lesson (1 line) → CTA  
**Hashtags:** 3-5 for FB, 5-8 for IG (sentence case, mix branded + discovery)  
**Tone:** Conversational, educational, storytelling

**Formula:**
```
[Hook question or statement from VO opening]

[Concrete example 1 from video]
[Concrete example 2 from video]
[Optional: Customer quote or stat]

[One-line lesson/takeaway]

[CTA call to action]
📱 [Phone number]

#Brand #Topic #Location #Category #Niche
```

---

### TIKTOK (Viral + Punchy)

**Length:** 30-60 words max  
**Structure:** Ultra-punchy hook (3-5 words) → Key tension/contrast → Viral question/ask  
**Hashtags:** 5-8 (mix trending + niche)  
**Tone:** Direct, edgy, scroll-stopping

**Formula:**
```
[Ultra-short hook — 3-5 words max]

[Key tension/contrast from video — one line]

[Viral question or challenge]

#Trending #Niche #Location #Category #ViralFormat #Brand
```

**TikTok-specific tactics:**
- Start with ALL CAPS hook (attention grab)
- Use emojis strategically (1-2 max, meaningful not decorative)
- End with question or challenge (drives comments)
- Keep hashtags discoverable (mix viral + niche)

---

### YOUTUBE SHORTS (SEO + Search)

**Title:** 60 characters max (front-load keywords)  
**Description:** 150 words (detailed, keyword-rich, valuable)  
**Structure:** Title hook → Description (what/why/how) → CTA + subscribe ask  
**Hashtags:** 3-5 in description  
**Tone:** Informative, searchable, value-first

**Title Formula:**
```
[Keyword] vs [Keyword]: [Unexpected Result/Benefit]
```

**Description Formula:**
```
[Restate title question/topic]

[What viewers will learn — 2-3 key points from video]

[Why this matters — practical application]

[How to apply — one action step]

[CTA: Phone number for [specific benefit]]

👉 Subscribe for more [topic] tips from Ghana

#Keyword1 #Keyword2 #Brand
```

**YouTube-specific tactics:**
- Front-load keywords in title (search ranking)
- First 2 lines of description = mini-hook (shows in search preview)
- Include timestamps if 60s+ (Shorts algorithm likes structure)
- End with subscribe CTA (channel growth)

---

### WHATSAPP STATUS (Direct + Minimal)

**Length:** 25-50 words, 4-6 short lines  
**Structure:** Short punchy lines (3-7 words each) → Phone number (bare)  
**Hashtags:** NONE (WhatsApp doesn't use hashtags)  
**Tone:** Direct, conversational, text-message style

**Formula:**
```
[Hook line 1]
[Hook line 2 — contrast or payoff]

[Key takeaway or question]

[Bare phone number]
```

**WhatsApp-specific tactics:**
- Short lines (3-7 words max per line)
- No hashtags (looks spammy)
- Phone number LAST LINE, bare (no "Call:" prefix)
- Emoji optional (1 only, meaningful)
