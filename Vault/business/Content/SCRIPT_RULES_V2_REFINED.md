## 🔄 WHAT CHANGED (Before → After)

### 1. TEXT PILLS: Simplified (7 → 3 max)

**❌ OLD RULE (Too cluttered):**
- 7+ text pills per video
- Example: "GHANA MORNING", "UK MORNING", "FREE ALARM", "NEVER FAILS", "YOU CAN'T SNOOZE A COCKEREL", "Real tools. Real prices.", "0204252252"

**✅ NEW RULE (Max 3):**
1. **Series identifier** (0-5s): "GHANA MORNING" / "RED FLAG" / "AKOMA ROBOTICS" / "PRODUCT SHOWCASE"
2. **ONE key payoff line** (11-23s): The most memorable quote (e.g., "YOU CAN'T SNOOZE A COCKEREL")
3. **Phone CTA** (25-28s): "0204252252" (always last, always prominent)

**Result:** Cleaner screen, Taiwah's face more prominent, less text competition.

---

### 2. PROPS: Two Types (Taiwah-Held + Stock Props)

**❌ OLD RULE (Only what Taiwah holds):**
- Props = drill, wrench, tape measure (actor holds)
- No guidance on additional props

**✅ NEW RULE (Two types):**

**Type A: Taiwah-Held Props**
- What the actor physically holds in-hand
- Examples: tape measure, drill, level, wrench, glue bottle, circuit board
- Varies by series:
  - Mon UK-Ghana lifestyle: Generic everyday tool (tape measure, level)
  - Tue Red Flag: Tool relevant to topic (level for "building straight", tape for "measure twice")
  - Wed Akoma: Robotics kit component (mBot wheel, circuit board) OR hands-only gesture
  - Thu Product: THAT specific product (if showcasing Gorilla Glue, hold Gorilla Glue)
  - Fri-Sun 2Real: Vary by concept (tape measure safe default, power tool if product-led)

**Type B: Stock Props (from stock footage)**
- Additional items in scene from stock video/photos
- Examples: alarm clocks on bedside table, tools on workbench, construction materials, UK vs Ghana comparison items
- Enhances environment/comparison without Taiwah holding everything

**Example script note:**
```
Props:
- Taiwah-held: Tape measure (yellow Tapelet, actor holds)
- Stock props: Alarm clock (UK bedside table), cockerel (Ghana fence), traffic comparison (empty road vs busy road)
```

---

### 3. RESOLUTION TARGET: Tiered (Primary → Acceptable → Minimum)

**❌ OLD RULE (Vague):**
- "Export at high resolution"
- No specific targets

**✅ NEW RULE (Tiered targets):**

**Primary target:** **1080×1920** (full HD vertical)
- Best quality for IG/TikTok/YouTube Shorts
- Crisp text pills, clear Taiwah face details
- Aim for this whenever possible

**Acceptable:** **720×1280** (HD vertical)
- If rendering constraints or export limits
- Still good quality, slightly softer
- Posts fine to all platforms

**Minimum:** **480×854** (SD vertical)
- Higgsfield output limit (acceptable)
- Text pills still readable
- Slightly softer but usable

**Script note:** "Export at 1080×1920 primary; 720×1280 acceptable if rendering constraints"

---

### 4. STOCK INTEGRATION: Optional (Not Mandatory)

**❌ OLD RULE (Implied required):**
- Stock photos specified in every script
- User felt obligated to source them

**✅ NEW RULE (Optional, strategic use):**

**When to use stock:**
- Direct visual comparison needed (UK alarm clock vs Ghana cockerel)
- B-roll texture (construction site, workshop close-ups, materials)
- Props user doesn't physically have (alarm clock, UK bedroom, cockerel on fence)

**When to skip stock:**
- Taiwah-only videos work GREAT (simpler, more authentic)
- Concept doesn't need comparison visuals
- Story is Taiwah-led (personal experience, customer testimonial)

**Script note options:**
- "Stock optional: UK alarm clock for direct comparison"
- "Taiwah-only works here (no stock needed)"
- "Stock props available: tools on bench, wood shavings, workshop environment"

**Result:** User doesn't feel pressured to source stock for every video; Taiwah-centered content encouraged.

---

### 5. OVERLAYS: Strategic Use (Popular on Viral Videos)

**❌ OLD RULE (Not mentioned):**
- No guidance on overlays

**✅ NEW RULE (Consider strategically):**

**Overlay types:**
- **Text overlays:** Key stats, comparisons, before/after numbers (e.g., "270 cedis ÷ 3 jobs = 90 cedis/job")
- **Graphic elements:** Arrows, circles, highlight boxes (e.g., circling tool feature, arrow pointing to price)
- **Comparison split-screens:** Side-by-side UK vs Ghana, before/after, cheap vs quality

**When to use:**
- Mon UK-Ghana: Side-by-side split-screen (Ghana morning left, UK morning right)
- Tue Red Flag: Text overlay highlighting problem (e.g., "No written quote = RED FLAG")
- Thu Product: Graphic element circling product feature (e.g., "Gorilla bond holds 2 tons")
- Fri-Sun 2Real: Stats overlay (e.g., cost-per-job math: "600 ÷ 50 = 12 cedis/job")

**Script note:** "Overlay opportunity: Side-by-side Ghana cockerel (left) vs UK alarm (right) during VO comparison"

**Result:** Scripts suggest overlays when strategically valuable (viral video tactic); not mandated every video.
