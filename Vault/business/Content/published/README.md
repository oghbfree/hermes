# Published Archive

Completed, verified-publication assets move here (or their permalink/evidence is noted here). The canonical weekly log is `../content-output/sent-log.md`.

## How to use
- One entry per published piece: title, date, channels, permalink if available, any metrics (views/chats/sales).
- Metrics power the repurposing decisions in `../repurpose/queue.md`.
- Periodically run: "Update the content archive from the published folder."

See `CONTENT_CALENDAR.md` → Published Archive for the consolidated by-week record.
