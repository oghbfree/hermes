# 💧 Farm Water System — Integrated Drainage + Storage

**Principle**: Drain *to* storage, not *away*. Every drop = dry season irrigation bank.

---

## 🎯 System Overview

```
HIGH GROUND (upper farm)
    │
    ▼  [Contour Ditch 1] ───► [Infiltration Pit / Mini-Pond]
    │
    ▼  [Contour Ditch 2] ───► [Infiltration Pit / Mini-Pond]
    │
    ▼  [Main Collector Ditch] ──► [MAIN FARM POND / DUGOUT at lowest point]
    │                                       │
    │                    ┌──────────────────┴──────────────────┐
    │                    ▼                                     ▼
    │            [Overflow Pipe]                            [Irrigation Outlet]
    │              (50 mm PVC)                                (Treadle/Solar Pump)
    │                    │                                     │
    ▼                    ▼                                     ▼
SAFE EXIT          STREAM/ROAD                           CROP BEDS
```

## 📐 Phase 1 — Emergency (This Week, In Rain)

### **Contour Ditches**
| Spec | Detail |
|------|--------|
| Depth | 30–40 cm |
| Width | 30 cm |
| Spacing | Every 10–15 m vertical drop |
| Grade | 0.5–1% (barely flowing — infiltrates) |
| Length | Total ~200–300 m across farm |
| Material | Hand-dug (hoe/mattock), 2–3 people, 1 day |

### **Main Collector Ditch**
| Spec | Detail |
|------|--------|
| Depth | 40–50 cm |
| Width | 40 cm |
| Route | Connects all contour ditches → pond |
| Grade | 1–2% (moves excess fast) |
| Lining | Vetiver grass on banks (plant immediately) |

### **Main Pond / Dugout**
| Spec | Detail |
|------|--------|
| **Starter** | 3 × 3 × 1.5 m = 13,500 L (dig by hand, 1 day) |
| **Target** | 5 × 5 × 2 m = 50,000 L (expand in dry season) |
| **Location** | Lowest point of farm (where water naturally ponds) |
| **Bund** | Downstream side — soil from excavation, compacted, vetiver planted |
| **Inlet** | Silt trap (1×1×0.5 m pit) + 1 m vetiver/grass filter strip |
| **Outlet** | 50 mm PVC overflow pipe at 150 cm level → safe exit (stream/road ditch) |
| **Lining** | **Decision needed**: Clay puddling (free, test soil) vs HDPE liner (GHS 800–1,200) |
| **Cover** | Shade net / palm fronds / floating plants (azolla) — reduce evaporation 60–80% |
| **Fence** | Bamboo stakes + chicken wire (keep goats/kids out) |

### **Soil Test for Clay Puddling (Do Today)**
```
1. Dig to subsoil (below topsoil) at pond site
2. Wet handful — roll into sausage (1 cm thick, 10 cm long)
3. Bend into ring:
   - Holds shape, no cracks → CLAY WORKS (puddle in layers, stomp until shiny)
   - Crumbles / cracks → NEED LINER or import clay
```
