# 🥋 SENSEI — Book → Execution Coach

Sensei (harold profile) turns non-fiction books/PDFs into **actionable skills + coaching routines** so you actually execute what you read.

## Structure
| Folder | What lives here |
|--------|-----------------|
| `<Book>/FRAMEWORK.md` | The distilled "what to DO" — rules → triggers → actions |
| `<Book>/CHECKLIST.md` | Daily/weekly "did you do X" — the coaching tracker |
| `<Book>/PROGRESS.md` | Log of check-ins + progress over time |

## Get started
Give Sensei a book (PDF, pasted text, or summary) → it scaffolds a folder here + a coaching routine + (optionally) a cron check-in.

## Rules
- Extracts **execution**, not summaries.
- Coaches one question per day, one message, then stops.
- A completed book's routine either keeps, slows to weekly, or archives — decided by H.
