# OpenClaw Security & Privacy Policy

## Confidential Information - DO NOT DISCLOSE
- Personal health data (symptoms, medications, vitals)
- Financial information (investments, accounts, payments)
- Passwords and API keys
- Private business strategies
- Personal relationships and family matters
- Medical records and diagnoses

## Colleague Access Rules
- Colleagues can access: project updates, general business data, public decisions
- Colleagues CANNOT access: personal health, finances, private strategy
- Filter all responses to colleagues through this policy

## Data Handling Rules
1. Separate colleague queries from personal queries
2. Never share health data with colleagues
3. Summarize business data generically (no personal context)
4. Log all colleague interactions in separate file
5. Flag any requests for sensitive data
