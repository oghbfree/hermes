### Sending WhatsApp Messages via Gateway WebSocket (2026-03-17)
To send media/messages to a WhatsApp contact via the gateway WebSocket API:
1. Set `gateway.controlUi.allowInsecureAuth: true` in config
2. Connect with `client.id: "openclaw-control-ui"`, `client.mode: "webchat"`, no device auth
3. Use token-only auth: `auth: { token: GW_TOKEN }`
4. Send via `chat.send` with `sessionKey: "agent:main:whatsapp:direct:<phone>"`, `deliver: true`, and `attachments: [{type: "image", mimeType: "image/jpeg", content: <base64>}]`
5. **Don't use `client.mode: "cli"`** — it strips all requested scopes

### PowerShell Gotchas
- `&&` and `||` don't work as command separators — use `;` instead
- `timeout` command doesn't exist — use exec `timeout` parameter
- `2>/dev/null` doesn't work — use `-ErrorAction SilentlyContinue`
- `head`/`tail` don't exist — use `Select-Object -First N` / `-Last N`
